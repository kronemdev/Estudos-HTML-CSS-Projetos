# 🔐 Tela de Login Moderna (Dark Mode)

Uma interface de autenticação elegante com design moderno em modo escuro, desenvolvida com HTML5 e CSS3. O projeto foca em uma experiência de usuário limpa, utilizando efeitos visuais avançados de sombreamento e transições.

## 🚀 Funcionalidades Visuais e Recursos

* **Fundo em Gradiente:** Transição suave de cores (`linear-gradient`) do roxo para o preto.
* **Efeito Glassmorphism Simples:** Caixa de login escura com semi-transparência (`rgba`) e bordas sutis.
* **Layout Centralizado:** Uso avançado de Flexbox para manter o formulário perfeitamente centralizado em qualquer tamanho de tela (`100vh`).
* **Botão Interativo (Hover):** Mudança de cor dinâmica e suave quando o usuário passa o mouse sobre o botão de envio.
* **Campos Padronizados:** Inputs e botões com tamanhos consistentes, cantos arredondados e foco na legibilidade.

## 🧠 Conceitos CSS Praticados

* Alinhamento bidimensional com **Flexbox** (`justify-content` e `align-items`).
* Manipulação de cores com opacidade (`rgba`) e degradês (`linear-gradient`).
* Efeitos de profundidade com sombras projetadas (`box-shadow`).
* Pseudo-classes de interação (`:hover`) e estilização de estados de validação (`:valid` / `:invalid`).

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação semântica do formulário)
* **CSS3** (Estilização avançada e responsividade)
