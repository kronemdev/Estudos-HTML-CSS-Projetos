# 📜 Projeto: Cordel Moderno

Este repositório contém a resolução do desafio "Cordel Moderno", proposto pelo professor Gustavo Guanabara no curso de HTML5 e CSS3 (Curso em Vídeo). O projeto combina a literatura de cordel de Milton Duarte com técnicas avançadas de design web moderno.

## 🚀 Funcionalidades e Recursos

* **Efeito Parallax:** Uso da propriedade `background-attachment: fixed` para travar as imagens de fundo enquanto o texto rola, criando um efeito de profundidade impressionante.
* **Design Responsivo (Mobile First/Adaptável):** Uso de `@media queries` para adaptar o tamanho das caixas de texto e desativar o efeito parallax em telas de celulares, garantindo uma navegação suave.
* **Tipografia Customizada:** Estrutura configurada para registrar e renderizar a fonte temática local através da diretiva `@font-face`.
* **Layout Semitransparente (Glassmorphism):** Caixas de texto escuras sobrepostas às imagens utilizando opacidade com cores `rgba()`, melhorando o contraste e a leitura.

## 🧠 Conceitos Praticados

* Centralização e alinhamento de blocos utilizando **Flexbox** (`display: flex` e `align-items`).
* Manipulação avançada de backgrounds com `background-size: cover` e `background-position`.
* Organização de herança e seletores de classes reutilizáveis (como as variações de imagem via `.foto02`).
* Controle absoluto de fluxo de texto com `overflow-wrap: break-word` para evitar quebras de layout.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação de blocos e estrofes de poesia)
* **CSS3** (Efeitos de background fixo e responsividade)
