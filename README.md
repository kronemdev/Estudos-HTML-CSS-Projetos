# 🚀 Meus Projetos e Desafios Front-End

Bem-vindo ao meu repositório central de estudos em desenvolvimento web! Este espaço foi criado para organizar, documentar e estruturar a minha evolução técnica em **HTML5** e **CSS3**, reunindo telas de login modernas e os famosos desafios práticos do Curso em Vídeo.

---

## 📁 Projetos no Repositório

Aqui estão os projetos desenvolvidos, organizados por suas respectivas pastas com links diretos:

### 📜 [Desafio Gustavo Guanabara 02](./Desafio%20Gustavo%20Guanabara%2002)
A famosa página do **Cordel Moderno** baseada na poesia de Milton Duarte.
* **O que pratica:** Efeito **Parallax** (`background-attachment: fixed`), alinhamento com Flexbox, uso de opacidade (`rgba`) para contraste de texto e design responsivo para celulares.

### 🤖 [Desafio Gustavo Guanabara](./Desafio%20Gustavo%20Guanabara)
O site completo contando a **História do Mascote do Android**.
* **O que pratica:** Semântica avançada do HTML5 (`<aside>`, `<nav>`, `<section>`), limites fluidos de layout (`max-width`), estilização com degradês lineares e incorporação de vídeos via `<iframe>`.

### 🔐 [Tela de Login](./tela-login)
Uma interface moderna de autenticação com estética voltada para o modo escuro (*Dark Mode*).
* **O que pratica:** Fundo em gradiente suave, efeito *glassmorphism* na caixa de formulário, efeitos de profundidade com `box-shadow` e pseudo-classes de interação do usuário (`:hover`).
