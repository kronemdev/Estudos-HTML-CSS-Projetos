# 🤖 Projeto: História do Mascote do Android

Este repositório contém a resolução de um dos desafios mais icônicos do curso de HTML5 e CSS3 do professor Gustavo Guanabara (Curso em Vídeo). O objetivo principal foi criar uma página rica em conteúdo, altamente estilizada, com foco em semântica e adaptabilidade de tela.

## 🚀 Funcionalidades e Recursos

* **Semântica HTML5 Avançada:** Uso correto de tags estruturais como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`.
* **Mídia Incorporada:** Inclusão responsiva de imagens e de um vídeo externo utilizando a tag `<iframe>` do YouTube.
* **Layout Fluido:** Aplicação de limites de largura (`max-width: 960px` e `min-width: 250px`) combinados com margens automáticas para manter o site centralizado e legível em monitores grandes.
* **Estilização com Degradê:** Uso de `linear-gradient` tanto no cabeçalho (vertical) quanto nos títulos de seção (horizontal).
* **Multi-colunas:** Organização da lista de versões do Android em duas colunas utilizando a propriedade CSS `columns: 2`.
* **Tipografia Customizada:** Estrutura preparada para o registro e renderização de fontes externas locais via `@font-face`.

## 🧠 Conceitos Praticados

* Seletores descendentes e seletores de filhos diretos em CSS (`header > h1`).
* Efeitos visuais de profundidade com sombreamento de textos (`text-shadow`) e blocos (`box-shadow`).
* Controle e comportamento de imagens fluidas (`width: 100%; height: auto;`).
* Pseudo-classes de interação do usuário (`:hover`) na barra de navegação.

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3** (Estilos incorporados internamente via tag `<style>`)
